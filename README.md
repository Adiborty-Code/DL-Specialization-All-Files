# Deep Learning Specialization

This repository contains all the files, notes, assignments, and code completed while taking the "Deep Learning Specialization" course on Coursera.

## About the Course

This specialization provides a strong foundation in deep learning concepts, architectures, and practical implementation techniques. It covers both theoretical understanding and hands-on model development across multiple deep learning domains.

Topics covered include:

- **Neural Networks and Deep Learning** – Fundamentals of deep neural networks, forward/backward propagation, and model training  
- **Improving Deep Neural Networks** – Hyperparameter tuning, regularization, optimization algorithms, and batch normalization  
- **Structuring Machine Learning Projects** – Error analysis, bias-variance tradeoff, and best practices for building ML systems  
- **Convolutional Neural Networks (CNNs)** – Computer vision, image classification, object detection, and face recognition  
- **Sequence Models** – RNNs, LSTMs, GRUs, attention mechanisms, transformers, and NLP applications
